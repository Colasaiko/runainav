# ============================================================
# TDK Title Pattern Rules（强制规范）
# ============================================================

【Title 规则】

规则1：Title 字符数：20～30（Array.from(text).length 计算，中英文数字标点空格各算1字符）
规则2：禁止 .slice() / substring() 截断
规则3：相邻 10 篇文章至少使用 4 种不同 Title 句式

可用 Title 句式类型（必须轮换）：

A. 大词型
   例：2026机场推荐：稳定、价格与线路怎么选

B. 问题型
   例：晚高峰总是卡？稳定机场怎么判断

C. 人群型
   例：Windows用户怎么选Clash Verge订阅

D. 场景型
   例：ChatGPT国内使用网络怎么选？机场选择指南

E. 比较型
   例：IPLC、IEPL与中转有什么区别？

F. 购买型
   例：不限时流量包值得买吗？按量计费怎么选

G. 教程型
   例：Cursor搭建网站教程：从创建到部署

H. 对比型
   例：Cursor和GitHub Copilot怎么选？


# ============================================================
# Description Pattern Rules（强制规范）
# ============================================================

【Description 规则】

规则1：Description 字符数：70～80（Array.from(text).length，同上规则）
规则2：禁止所有 Description 统一以"本文从……"开头

可用 Description 开头句式（必须轮换）：

问题型：   晚高峰经常卡顿，不一定只是速度问题……
人群型：   如果你主要在 Windows 使用……
场景型：   使用 ChatGPT、Claude 等海外 AI 时……
比较型：   IPLC、IEPL和普通中转有什么区别……
购买型：   第一次购买机场应该月付还是年付……
决策型：   价格最低不代表长期成本最低……
教程型：   从安装、配置到实际使用……
