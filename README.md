## 🌟 About RunAI

随着 AI 工具越来越多，互联网工具、网络环境以及 AI 服务的访问方式也变得日益复杂。

RunAI 希望通过系统地整理**工具、教程、指南、评测与网络资源**，帮助每一位用户都能更轻松、更直观地找到适合自己的工具组合与网络解决方案。

这里没有夸张的营销词汇，只有实用、清晰的内容导航。

## 📁 Project Structure

根据当前项目架构，主要功能目录如下：

- `src/app/`: Next.js App Router 主路由及页面（如 `page.tsx`、`vpn` 等）。
- `src/components/`: 高度复用的 React UI 界面组件库。
- `src/data/`: 结构化数据和静态配置源（例如 `vpnBrands.ts`）。
- `public/`: 全局静态资源文件（如 favicon 与图片）。
